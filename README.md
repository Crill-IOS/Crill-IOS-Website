# 🌐 Crill-IOS · Official Website

**Crill-IOS** macht das Arbeiten mit Cisco IOS Konfigurationen einfacher, sicherer und effizienter.  
Wir bieten eine moderne VS Code Extension, ein interaktives Playground-Tool und eine ausführliche Dokumentation für Netzwerk-Admins & Engineers.  

---

## 🔎 About
Crill-IOS ist ein auf dem **Language Server Protocol (LSP)** basierendes Projekt, das speziell für **Cisco IOS**-Konfigurationen entwickelt wurde.  
Unsere Mission: **Fehlerfreie Konfigurationen** durch Autovervollständigung, Live-Validierung und intelligente Templates.
